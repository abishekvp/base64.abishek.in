# Base64 Pro Studio — `base64.abishek.in`

A professional, fullscreen, browser-based Base64 suite:
- **Text Encode/Decode:** UTF-8, ASCII, Latin-1, Standard RFC 4648, URL-Safe (`-_`), Padding control, 64/76 character line wrapping, and live statistics.
- **File to Base64:** Convert images, audio, video, PDF, fonts, and binaries into Data URIs, raw Base64, HTML embed tags, and CSS background snippets.
- **Base64 to File:** Magic-byte sniffing to auto-detect file formats (PNG, JPG, GIF, WebP, PDF, MP3, ZIP, SVG) with live audio/image preview and download.
- **Hex ↔ Base64:** Bidirectional byte-level conversions with space, colon, and 0x prefix formatting.
- **Data URI Inspector:** Deconstructs any Data URI into MIME type, charset, encoding, payload size, with live render preview.
- **Hashes & Checksums:** Real-time MD5 and SHA-256 calculation.
